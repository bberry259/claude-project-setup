# TODO.md

## How to use this document

Active items only. This is a working list, not an archive.

**Completion rule:** when a task is finished, delete it from this document. Do not mark it done, do not move it to a completed section. If the completion is noteworthy, record it in CHANGELOG.md. If completing a task spawns new tasks, add them here at the appropriate priority level.

**What belongs here:** tasks that need doing, grouped by priority, with enough context to act on them. Open questions that need answering before work can proceed.

**What does NOT belong here:** completed work, project state (HANDOVER.md), or session history (CHANGELOG.md).
